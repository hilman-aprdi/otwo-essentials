# O2 Essentials

Website catalog for **O2 Essentials**, an Indonesian fashion brand focused on oversized t-shirts and everyday fashion essentials.

This project is built with Next.js and Tailwind CSS to showcase collections, product details, campaign banners, and marketplace links.

## Tech Stack

- Next.js App Router
- React
- Tailwind CSS
- Static product data

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
